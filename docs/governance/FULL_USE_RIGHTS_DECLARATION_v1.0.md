# Mr.liou 完整使用權宣告 v1.0

## 唯一核心

Mr.liou 對其原始輸入、MRL / MrLiouWord 正本、程式、設定、文件、資料、分支、鏡像、部署與依法可歸屬的衍生產物，保留完整使用權與最終行使權。

本宣告優先處理「能否繼續使用、移動、修改、執行與發布自己的系統」；平台名稱、Repo 顯示、AI Agent、託管、付款或網域綁定都不得在內部 Canon 中默認取消或轉移此使用權。

## 完整使用權包含

- 存取、執行與持續運行；
- 複製、下載、匯出、備份、封存與還原；
- 修改、重構、適配、分支、合併與重建；
- 部署、託管、發布、散布與商業使用；
- 在不同平台、網域、伺服器與供應商之間遷移；
- 從外部平台移除自己的產物；
- 撤銷已授予的內部存取或分支管理權；
- 核准、拒絕或停止衍生版本成為正式 Canon。

## 適用範圍

- `main`；
- 所有現在與未來分支；
- 組織鏡像與 Repo 投影；
- AI 協作實作；
- 外部平台投影；
- 網域與部署；
- 套件、Release、匯出檔與生成產物。

分支可以由不同 steward 管理，但不轉移 Mr.liou 的完整使用權、最終行使權或裁決權。

## 平台角色

外部平台只能按實際角色記錄為：工具、執行平台、託管、計費、投影或實作協助。

以下行為本身不構成使用權轉移：

- 在平台上執行或生成；
- 由平台託管；
- 綁定 Custom Domain；
- 經平台付款；
- 由 AI Agent 建立 PR 或檔案；
- Repo owner、commit author 或平台名稱出現在介面上。

任何外部合約或法律限制都必須明確記錄，不能以平台預設、隱藏 metadata 或單向匯入默默改變母體使用權。

## Möbius 使用權閉環

每次向外平台、分支或部署展開，都必須保留：

1. 可匯出路徑；
2. 可回到正本母體的路徑；
3. 可回滾或重建的路徑；
4. 來源、版本與 Hash；
5. `final_approver: Mr.liou`。

無法匯出、無法回到母體或無法重建時，標記為 `USE_RIGHTS_CLOSURE_FAILURE`，不得視為正式完成。
